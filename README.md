# Cars Dealership Capstone Project

## Project Overview
A responsive full-stack web application for a national car dealership retailer in the United States.

## Features
- View dealership branches and dealer details.
- Register, log in, and log out.
- Submit and view dealership reviews.
- Filter dealers by state.
- Analyze review sentiment.
- Use a responsive React frontend with a Django backend.
- Support CI/CD and containerized deployment.

## Technologies
- Frontend: React, HTML, CSS, Bootstrap
- Backend: Django, Django REST Framework
- Database: SQLite and MongoDB components
- DevOps: Git, GitHub Actions, Docker, Kubernetes
- Deployment: IBM Cloud Code Engine
